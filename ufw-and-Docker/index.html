问题描述

Docker默认使用iptables管理容器端口对外开放与否，但如果我们使用ufw来管理防火墙，Docker容器会忽略ufw的规则，导致ufw无法控制Docker容器端口开闭。

这是很不安全的，因为有些容器只需要在内网提供服务，现在被Docker给暴露出来了。

正确的解决方法

上面的方法虽然能让Docker端口服从ufw管理，但是不适合在生产环境中使用。一个是为了使ufw能够管理Docker容器端口，修改了4个文件；一个是为了一个容器放行了一个端口，导致该端口上所有的服务都能被访问。

此时，要对外暴露端口，就不能再使用ufw allow了，放行端口的方法可以查看此处。

当然，我们并不需要手动添加这些内容，也不需要每次输入这么复杂的命令来控制容器端口开闭。

https://github.com/chaifeng/ufw-docker 直接提供了一个工具，可以自动添加这些规则，只需要按照这里的步骤下载安装并开始使用即可。
现在，比如我想要放行nginx容器的80端口，只需要执行ufw-docker allow nginx 80；如果想暴露nginx容器的全部端口，执行ufw-docker allow nginx就可以了。

注意这里放行的是容器端口，而不是映射到宿主机的端口。
