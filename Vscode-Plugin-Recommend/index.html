Vscode 插件推荐

Katorly2024-08-09

本篇推荐的均为免费版，或不需要用到其收费功能的插件。
排名不分先后，按照字母顺序排序。

Vscode经常把比较受欢迎的插件功能在后续版本整合进内置里，这里不再推荐在本篇文章发表之前就已经被整合进内置的插件。

以下插件截图均来自于插件自身在Visual Studio MarketPlace中上传的图片。

功能性

Better Align

插件链接：https://marketplace.visualstudio.com/items?itemName=Chouzz.vscode-better-align

更美观的自动对齐。

Better Comments

插件链接：https://marketplace.visualstudio.com/items?itemName=aaron-bond.better-comments

用不同的符号给代码注释打上颜色。

CodeSnap

插件链接：https://marketplace.visualstudio.com/items?itemName=adpyke.codesnap

代码截图自动美化工具，所见即所得。

Error Lens

插件链接：https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens

直接用颜色标注代码有警告或报错的那一行，并在末尾标注相应的信息，不需要再将鼠标悬浮在代码上即可看到警告/报错信息。
这个插件IntelliJ IDEA那边也有一个类似的，但是经常异常所以就没在那边推荐了。

GitHub Repositories

插件链接：https://marketplace.visualstudio.com/items?itemName=GitHub.remotehub

查看和编辑远程Github仓库。

GitLens

插件链接：https://marketplace.visualstudio.com/items?itemName=eamodio.gitlens

提供Git相关的一系列功能。该插件免费版只对开源的仓库有效。



Image preview

插件链接：https://marketplace.visualstudio.com/items?itemName=kisstkondoros.vscode-gutter-preview

在代码行数旁边和鼠标悬浮时显示图片预览。

IntelliCode

插件链接：https://marketplace.visualstudio.com/items?itemName=VisualStudioExptTeam.vscodeintellicode

Microsoft推出的智能代码Object补全，官方介绍见此。

IntelliCode API Usage Examples

插件链接：https://marketplace.visualstudio.com/items?itemName=VisualStudioExptTeam.intellicode-api-usage-examples

随时查看当前使用的库函数在Github上的用例，由Microsoft推出。

Markdown All in One

插件链接：https://marketplace.visualstudio.com/items?itemName=yzhang.markdown-all-in-one

强大的多合一Markdown编辑器工具箱。



Web开发

Color Highlight

插件链接：https://marketplace.visualstudio.com/items?itemName=naumovs.color-highlight

用颜色代码高亮颜色代码。

CSS Peek

插件链接：https://marketplace.visualstudio.com/items?itemName=pranaygp.vscode-css-peek

使CSS类能像函数调用一样被查看。

Five Server

插件链接：https://marketplace.visualstudio.com/items?itemName=yandeu.five-server

提供实时Web预览，在Live Server的基础上，添加了定位代码的功能。

SVG

插件链接：https://marketplace.visualstudio.com/items?itemName=jock.svg

提供SVG预览和辅助编辑等功能。

Thunder Client

插件链接：https://marketplace.visualstudio.com/items?itemName=rangav.vscode-thunder-client

在本地方便地进行GET、POST等与API交互的操作。

外观主题

这类插件比较多，适合自己的才是最好的。放出本人使用的图标主题和颜色主题。

Fluent Icons

插件链接：https://marketplace.visualstudio.com/items?itemName=miguelsolorio.fluent-icons

（IDE图标主题）

Material Icon Theme

插件链接：https://marketplace.visualstudio.com/items?itemName=PKief.material-icon-theme

（文件图标主题）

One Dark Pro

插件链接：https://marketplace.visualstudio.com/items?itemName=zhuangtongfa.Material-theme

（代码高亮颜色主题）

AI

这类插件较多，适合自己的才是最好的。这里只放一个免费的作参考用。

Codeium

插件链接：https://marketplace.visualstudio.com/items?itemName=Codeium.codeium
特点：

  • 多年无收费（企业用户除外）
  • 整段代码补全
  • 无使用限制
  • 可Chat

如有更多你想要推荐的插件，欢迎在评论区附上插件名称及其链接。
