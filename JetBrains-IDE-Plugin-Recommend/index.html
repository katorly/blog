本篇推荐的均为免费版，或不需要用到其收费功能的插件。JetBrains捆绑安装的插件不再赘述。
排名不分先后，按照字母顺序排序。

这些插件不仅限于IntelliJ IDEA这款IDE，JetBrains全系IDE均推荐使用这些插件。

以下插件截图均来自于插件自身在JetBrains MarketPlace中上传的图片。

功能性

Better Highlights

插件链接：https://plugins.jetbrains.com/plugin/12895

注释高亮插件，与Vscode中的BetterComments插件相似。

CodeGlance Pro

插件链接：https://plugins.jetbrains.com/plugin/18824

还原与Vscode中一样的右边滚动条显示代码缩略图。

Easy Code Screenshots

插件链接：https://plugins.jetbrains.com/plugin/20766

代码截图自动美化工具。截出来的图会包含当前使用的颜色主题等，所见即所得。

GitToolBox

插件链接：https://plugins.jetbrains.com/plugin/7499

提供Git相关的一系列功能，与Vscode中的GitLens插件相似。

Key Promoter X

插件链接：https://plugins.jetbrains.com/plugin/9792

以防你不记得IntelliJ中的快捷键。可以用快捷键的操作，如果你用鼠标操作了，会提醒你该操作可以用哪个快捷键。

Rainbow Brackets

插件链接：https://plugins.jetbrains.com/plugin/10080

用不同颜色使{} () <div></div>隔得再远也能分得清层次关系。

Smart Input

插件链接：https://plugins.jetbrains.com/plugin/20575

中国用户专属插件，自动在不同的场景下切换中英文输入法。例如，在注释中自动变为中文输入法，在代码中自动变为英文输入法，不再需要手动按Shift。

外观主题

这个分类有一堆主题，适合自己的才是最好的，这里放本人使用的图标主题插件和颜色主题插件。

Atom Material Icons

插件链接：https://plugins.jetbrains.com/plugin/10044

One Dark Theme

插件链接：https://plugins.jetbrains.com/plugin/11938

AI

这个分类有一堆插件可用，适合自己的才是最好的，这里只放一个免费的作参考用。

Codeium

插件链接：https://plugins.jetbrains.com/plugin/20540
特点：

  • 多年无收费（企业用户除外）
  • 整段代码补全
  • 无使用限制
  • 可Chat

如有更多你想要推荐的插件，欢迎在评论区附上插件名称及其链接。
