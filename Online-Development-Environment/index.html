免费云开发环境（CDE）推荐

记录几个有免费套餐的在线云开发环境（CDE，Cloud Development Environment）（可以理解为在云端的VS Code、JetBrains IDE等），以靠谱和良心程度排序。不定期更新。

这种开发环境不同于vscode.dev、github.dev等VS Code Browser，这种云开发环境是类似code-server的服务，可以直接在线运行Java、PHP等，没有扩展安装限制，甚至还可以在里面跑Docker容器。

Paas（不需要自己有云服务器）

Gitpod

免费套餐：每月50小时，最多4个同时运行的环境，30分钟无操作自动断开。

支持在浏览器中打开VS Code并使用，此外支持使用VS Code Desktop、JetBrains Gateway通过SSH连接到云开发环境。

遗憾的是，Gitpod在2024年10月1日宣布发布Gitpod Flex（自托管的云开发环境），并将于2025年2月彻底停止原有的Paas服务。也就是说，现在要体验Gitpod，只能部署在自己的服务器上了，不能再使用它现成的云服务。

Gitpod在2024年10月1日前的定价：https://web.archive.org/web/20240822131147/https://www.gitpod.io/pricing

GitHub Codespaces

免费套餐：每月120核时（1CPU核心=1小时），总共15GB的存储空间。

支持在浏览器中打开VS Code并使用，此外支持使用VS Code Desktop、JetBrains Gateway通过SSH连接到云开发环境。

定价：https://docs.github.com/zh/billing/managing-billing-for-your-products/managing-billing-for-github-codespaces/about-billing-for-github-codespaces

CodeAnywhere

免费套餐：4核8G内存的环境，每月20小时，最多1个同时运行的环境，15分钟无操作自动断开。

定价：https://codeanywhere.com/pricing

Lapdev

免费套餐：4核的环境，每月30小时，最多3个同时运行的环境。

定价：https://lap.dev/pricing

Iaas（需要自己有云服务器来部署）

Coder

社区版完全免费，自用完全无限制。

支持noVNC、在浏览器中直接打开VS Code使用、VS Code Desktop、JetBrains Gateway、Jupyter Notebook、Cursor等，可以在这里找到更多，会Terraform的甚至可以自己添加更多云上或本地的IDE支持。

部署完成后需要自己配置Terraform模板才能新建环境，难懂且非常耗时。使用过程中还可能出现各种问题需要自己操心。

下面给出一些模板供参考（基本都可以直接拿来用）：

  • https://github.com/coder/coder/blob/main/examples/templates/community-templates.md
  • https://github.com/sharkymark/v2-templates
  • https://github.com/bpmct/coder-templates

如果在使用过程中遇到困难，可以加入其官方Discord求助社区，维护者都挺热心的。

Eclipse Che

完全免费。支持VS Code、JetBrains Gateway。需要用Kubernetes部署。
