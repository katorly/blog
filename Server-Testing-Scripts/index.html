融合怪

介绍: 全能的服务器测试脚本，包含“基础信息查询”、“CPU测试”、“内存测试”、“磁盘dd读写测试”、“磁盘fio读写测试”、“流媒体解锁”、“IP质量检测”、“三网回程”、“回程路由”、“测速节点测试”。

预览: https://blog.katorly.com/Dedicated-OVH-KSLEC-bhs/#%E8%9E%8D%E5%90%88%E6%80%AA

开源地址: https://github.com/spiritLHLS/ecs

YABS

介绍: 多维度服务器测试脚本，包含“系统基础信息”、“IPv6信息”、“磁盘fio测试”、“网络iperf测试”、“Geekbench测试”。

预览: https://blog.katorly.com/Dedicated-OVH-KSLEC-bhs/#YABS

开源地址: https://github.com/masonr/yet-another-bench-script

硬盘通电时间（适用于独服）

介绍: 测试硬盘通电时间和型号，支持多个硬盘，包含顺序读写测试。

预览: https://blog.katorly.com/Dedicated-OVH-KSLEC-bhs/#%E7%A1%AC%E7%9B%98%E9%80%9A%E7%94%B5%E6%97%B6%E9%97%B4

开源地址: https://github.com/Aniverse/A

三网去程

前往 https://ping0.cc/trace 选择起点节点并填入要测试的服务器IP地址（仅支持IPv4）进行测试。

预览: https://blog.katorly.com/Dedicated-OVH-KSLEC-bhs/#%E4%B8%89%E7%BD%91%E5%8E%BB%E7%A8%8B

三网回程

介绍: 三网回程线路测试，可测出三大运营商的回程线路，并标注线路质量。

预览: https://blog.katorly.com/VPS-ByteVirt-LA-China-Optimized/#%E4%B8%89%E7%BD%91%E5%9B%9E%E7%A8%8B

开源地址: https://github.com/zhanghanyun/backtrace

连续Ping测试

前往 https://ping.pe 填入要测试的服务器IP地址（支持IPv4和IPv6）即可开始测试。由于是连续测试，需要等待15分钟左右才能看到完整结果。

预览: https://blog.katorly.com/Dedicated-OVH-KSLEC-bhs/#%E8%BF%9E%E7%BB%ADPing%E6%B5%8B%E8%AF%95

IP质量检测

介绍: 带有精美排版的详细IPv4和IPv6质量检测，包含“IP基础信息”、“IP类型属性”、“风险评分”、“风险因子”、“流媒体及AI服务解锁检测”、“邮局连通性及黑名单检测”。

预览: https://blog.katorly.com/Dedicated-OVH-KSLEC-bhs/#IP%E8%B4%A8%E9%87%8F%E6%A3%80%E6%B5%8B

开源地址: https://github.com/xykt/IPQuality

网络质量检测

介绍: 带有精美排版的详细网络质量检测，包含“BGP信息”、“本地策略”、“接入信息”、“三网TCP大包延迟”、“三网回程路由”、“国内测速”、“国际互联”。

预览: https://blog.katorly.com/VPS-Crash-work-HK/#IP%E8%B4%A8%E9%87%8F%E6%A3%80%E6%B5%8B

开源地址: https://github.com/xykt/NetQuality

流媒体平台及游戏区域限制测试

介绍: 针对全球地区和各大洲地区的流媒体平台及游戏区域限制测试，支持IPv4和IPv6。包含的大洲、国家和地区有“国际”、“台湾”、“香港”、“日本”、“北美”、“南美”、“欧洲”、“大洋洲”、“韩国”。

预览: https://blog.katorly.com/Dedicated-OVH-KSLEC-bhs/#%E6%B5%81%E5%AA%92%E4%BD%93%E5%8F%8A%E6%B8%B8%E6%88%8F%E8%A7%A3%E9%94%81%E6%B5%8B%E8%AF%95

开源地址: https://github.com/lmc999/RegionRestrictionCheck
