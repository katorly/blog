小米 AX3000T 刷 OpenWrt

Katorly2025-04-04

演示材料：

  • 小米AX3000T路由器国行版（固件版本1.0.90）
  • OpenWrt 24.10.0

参考资料：
https://www.right.com.cn/forum/thread-8404780-1-1.html
https://post.smzdm.com/p/admxql3d

AX3000T现已不再需要降级到有SSH漏洞的固件版本1.0.47，直接使用xmir-patcher获取SSH权限即可。

外观展示

准备工作

在电脑下载如下文件：

  1. 前往 https://github.com/openwrt-xiaomi/xmir-patcher 下载整个仓库并解压，得到xmir-patcher-main文件夹，这是用于获取SSH权限的工具
  2. 前往 https://github.com/hanwckf/bl-mt798x/releases 下载bl-mt798x-release-*.7z，这是u-boot固件
  3. 前往 https://firmware-selector.openwrt.org 下载对应型号的OpenWrt固件，注意要下载SYSUPGRADE的那一个，例如本教程使用的专用小米AX3000T的OpenWrt24.10.0，文件名为openwrt-24.10.0-mediatek-filogic-xiaomi_mi-router-ax3000t-squashfs-sysupgrade.bin

之后，把AX3000T的LAN口（局域网口）用一根网线连接到电脑的网口上。注意还需要初始化AX3000T（接下来的操作需要用到初始化过程中设置的路由器后台密码）。

获取SSH权限

  1. 打开xmir-patcher-main文件夹，双击run.bat，在弹出的CMD窗口中可以看到菜单
  2. 输入1（1 - Set IP-address）并按回车，设置路由器的IP地址。如果不知道路由器的IP地址是多少，可以在电脑命令行执行ping miwifi.com来查看地址；如果仍然无法找到，可以手机下载米家APP并添加路由器，查看IP地址
  3. 输入2（2 - Connect to device）并按回车，输入路由器后台密码（初始化时设置的），之后可以看到SSH端口成功开启
  4. 输入4（4 - Create full backup）并按回车，备份整个分区，备份文件会被存放在xmir-patcher-main文件夹下的backup文件夹中
  5. 输入8（8 - Other functions）并按回车，再输入2（2 - Change root password）并按回车，修改SSH密码为自己想要的密码
  6. 输入0（0 - Return to main menu）并按回车，返回到主菜单
  7. 输入6（6 - Install permanent SSH）并按回车，安装永久SSH

之后，可以使用路由器IP地址:22+设置的SSH密码通过SSH工具登录到路由器SSH。

后续需要用到FTP上传文件到路由器SSH中，这里推荐使用免费的SSH工具WinSCP或MobaXterm。

  3. 使用SSH工具连接到路由器FTP（即路由器IP地址:21），上传刚刚选定的mt7981_ax3000t-fip-fixed-parts-multi-layout.bin或mt7981_ax3000t_an8855-fip-fixed-parts-multi-layout.bin文件

刷入OpenWrt

  1. 在u-boot界面中的Choose mtd layout处选择default。切勿选错！否则容易变砖！

  2. 点击选择文件并选择openwrt-24.10.0-mediatek-filogic-xiaomi_mi-router-ax3000t-squashfs-sysupgrade.bin，再点击Upload，等待进度条完成，路由器会自动重启。之后，OpenWrt成功完成刷入

全部工作完成后，记得将电脑的IP地址改回自动获取。
