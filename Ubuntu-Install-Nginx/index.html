防止泄露服务器IP

最佳实践是使用CDN。

这里以Cloudflare CDN为例，在DNS记录那里添加A和AAAA记录的时候开启“小黄云”，这样访问你的域名的时候就走的是Cloudflare CDN的IP地址，不会暴露源站服务器的IP。

但是即使开了“小黄云”，Nginx仍然“有办法”通过80和443端口泄露你的源站IP，即在没有server_name的时候默认执行第一个server块，导致源站IP通过SSL证书泄露。这就不得不进行下面的设置了。
